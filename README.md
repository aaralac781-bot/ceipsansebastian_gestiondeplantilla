# Gestión de Plantilla · CEIP San Sebastián

Aplicación de gestión de plantilla, horarios, sustituciones y comunicaciones del
**CEIP San Sebastián** (La Puebla del Río, Sevilla), integrada con el portal
**San Sebastián Net (SSNet)**.
